# Support

## An app scaffolded wrong or looks broken

[Open an issue](../../issues/new/choose). Say which app, and include the output of

```bash
npx @chatfuel/wizard doctor
```

with anything token-shaped redacted first — a token that reaches a public issue is a token to
rotate.

## The wizard itself misbehaved

That is the other repository:
[chatfuel-lab/chatfuel-wizard](https://github.com/chatfuel-lab/chatfuel-wizard/issues) — the
line is "the run failed" (wizard) versus "the run succeeded but the app is wrong" (here).

## You are writing an app and have a question

[Discussions](../../discussions) or the Discord: <https://discord.gg/TmrgcjVqFf>.
[docs/authoring.md](docs/authoring.md) answers most of it.

## You found a vulnerability

Do not open an issue. Use private vulnerability reporting — the Security tab, "Report a
vulnerability". [SECURITY.md](SECURITY.md) has the scope.

## What is not supported here

The Chatfuel product itself. Questions about the hosted dashboard, billing or the API's own
behaviour belong to Chatfuel support at <https://chatfuel.com>.
