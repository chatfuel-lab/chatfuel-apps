## Find the signal in your messages

Explore conversations as an interactive map. Filter a channel, open a group and read the messages behind it. The map keeps the big picture visible while you investigate a specific question.

## Keep the evidence with the insight

Find repeated wording, search within a group and exclude messages that do not belong. Save an observation and a next action with the matching source messages attached, then export the finding as JSON. A suggestion stays connected to the evidence you reviewed.

## Bring your messages and your categories

Import CSV or JSON, paste text, or preview recent incoming messages from connected conversations in your selected Chatfuel bot. Configure category definitions, scoring questions, business context and review thresholds. WhatsApp and Instagram conversation text can use the same workspace.

## Start immediately; connect analysis when ready

The included scenario map opens without a provider key or customer data. A vertical message stream and animated groups make it easy to explore the interface. The opening categories are scripted; playback is a visualization, not a model-speed benchmark.

Optional Jev analysis uses a server-side TypeSafe key and SDK authentication. Each run asks for confirmation before sending the selected messages, context and rules. Imported messages are never analyzed automatically.

## Built for the Chatfuel SDK

The preset includes the workspace, a read-only inbox importer, server adapter and an idempotent installation script. It uses the auth, channels and livechat modules without adding npm dependencies. Follow the playbook to register and verify the app in your scaffold.

Recent-inbox import is bounded; exhaustive history sync and standalone post-comment export are outside this version. Findings and imported data remain in the current tab until exported. The app does not send messages or execute the next actions it records.
